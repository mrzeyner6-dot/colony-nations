# Create API для торгового термінала (6.0.10, mc1.21.1)

Джерело: jar `create-6.0.10+mc1.21.1.jar` з Modrinth maven. Перевірено `javap` по байткоду, не по декомпіляції «на око». Create — обов’язкова залежність, код живе в `compat/create/`.

## Станція

Блок станції — `StationBlockEntity` (`com.simibubi.create.content.trains.station`).

```java
GlobalStation station = stationEntity.getStation();
String name = station.name;                 // публічне поле, може бути null або порожнім
Train present = station.getPresentTrain();  // null, якщо потяг тут не стоїть
```

`getStation()` бере edge point з `TrackTargetingBehaviour`. Поки станція не прив’язана до колії, повертає null: імені й потяга немає.

`getPresentTrain()` (байткод): бере `getNearestTrain()`, і повертає його лише якщо `train.getCurrentStation() == this`. Інакше null. Тобто потяг має саме зупинитись на цій станції (`currentStation` виставляється в `arriveAt` / `setCurrentStation`). Потяг, що проїжджає повз, не рахується. `getImminentTrain()` — інший метод, для пошти, ми його не використовуємо.

Радіус термінала міряється до **блока** станції, Чебишев (`terminalStationRadius`, за замовчуванням 3). Якщо таких станцій кілька, береться найближча з потягом: спершу менший Чебишев, потім менший квадрат Евкліда, потім менші x, y, z.

## Потяг і власник

`Train` (`com.simibubi.create.content.trains.entity.Train`):

- `id` — UUID потяга.
- `owner` — UUID гравця, **може бути null**. Конструктор кладе другий аргумент прямо в це поле. `write` пише NBT-ключ `Owner` лише коли UUID не null. `read` ставить null, якщо ключа немає.
- `name` — `Component`. Порожнє ім’я лишаємо порожнім рядком.
- `invalid` — такий потяг ігноруємо, ніби його немає.
- `getOwner(Level)` шукає **онлайн**-гравця через `PlayerList.getPlayer` і повертає null, якщо власника немає, гравець офлайн, або сервер кинув `IllegalArgumentException`. Для торгівлі це не годиться: офлайн-власник усе одно має UUID і може мати державу. Беремо поле `owner`, не `getOwner`.

## Що термінал робить з цими випадками

Держава власника — `NationRegistry.byOwner(owner)`, тобто гравець, у якого є `/nation`. Мешканець чужої держави без власної держави державою потяга не є.

| Стан | Обмін | Кредит |
| --- | --- | --- |
| У радіусі немає станції | монети лишаються в приймачі | — |
| Станція є, потяг не стоїть | те саме, у вікні назва найближчої станції | — |
| Потяг стоїть, `owner` — власник держави-продавця | не торгує (свій товар зі складу) | — |
| Потяг стоїть, у власника інша держава | продає за базовою ціною (мито — T27) | UUID тієї держави |
| Потяг стоїть, у власника немає держави | приватний покупець, базова ціна, ембарго на нього не розраховане (T27) | UUID гравця |
| Потяг стоїть, `owner == null` | теж приватний покупець | сталий UUID `TerminalTrade.UNOWNED` |

Монети без потяга власник забирає з приймача руками. Кредит, записаний до T26 на касу `TerminalTrade.COUNTER`, лишається рядком «Каса» і новими покупками не списується.
